# python-estudos

Repositório dedicado ao registro prático da minha evolução na linguagem Python, reunindo exercícios, anotações e códigos desenvolvidos durante os estudos.

---

## Estrutura do Repositório

O projeto é dividido em módulos progressivos:

### 01. Básico (`/01.basico`)
Fundamentos da linguagem, lógica de programação e estruturas de dados essenciais:
* `01.variaveis_e_condicionais.py`: Declaração de variáveis, tipos de dados e controle de fluxo (`if`, `elif`, `else`).
* `02.lacos.py`: Estruturas de repetição (`for`, `while`).
* `03.listas.py`: Manipulação de listas, métodos nativos e iteração.
* `04.dicionarios.py`: Estruturas chave-valor e manipulação de dicionários.
* `05.funcoes.py`: Criação de funções, parâmetros, retorno e escopo.

### 02. Programação Orientada a Objetos (`/02.poo`)
Aplicação dos pilares da POO para escrita de código modular e reutilizável:
* `01.classes_e_objetos.py`: Criação de classes, instanciação de objetos e construtores (`__init__`).
* `02.heranca.py`: Reutilização e extensão de comportamento entre classes.
* `03.encapsulamento.py`: Proteção de atributos e métodos, convenções de visibilidade e getters/setters.
* `04.polimorfismo.py`: Sobrescrita de métodos e tratamento uniforme de diferentes tipos.
